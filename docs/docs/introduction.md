# Introduction

**Fynvi Share** is a modern, self-hosted file sharing platform designed for reliable uploads, local-first storage, and a polished sharing experience.

Derived from Pingvin Share X 1.22.1, Fynvi Share combines quiet technical capability with an atmospheric Obsidian Aurora design system and robust transfer architecture.

## Features

- **Local-Storage-First**: Your files remain on your server without third-party lock-in.
- **Reliable Chunked Uploads**: High-speed, resumable multi-part upload pipeline.
- **Folder Support**: Upload and preserve directory structures via drag-and-drop.
- **Granular Share Controls**: Passwords, expiration dates, download count limits, and custom slugs.
- **Reverse Shares**: Allow external collaborators to securely submit files.
- **API Keys**: Exportable presets for third-party uploaders like ShareX.
- **Security & Identity**: Optional ClamAV antivirus inspection, TOTP two-factor authentication, OIDC and LDAP integration.
